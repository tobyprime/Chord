# Chord V1 测试流程

> 目标：验证「演奏者装 Mod、聆听者零安装听到」全链路，并覆盖 [design.md](design.md) §11 的四项待真机验证。
> 分五个阶段：先占位音色跑通链路（不依赖资源包），再上真实采样，最后压边界。

## 阶段 0：准备（约 20 分钟）

**构建产物**（已就绪，如有代码改动重新 `./gradlew build`）：
- `fabric/build/libs/fabric-0.1.0.jar` — 客户端 Mod
- `plugin/build/libs/plugin-0.1.0.jar` — Folia 插件（内置 protocol，单文件即用）

**服务端**：Folia 26.2（papermc.io 下载），JDK 25 运行，`eula.txt=true`，默认配置即可。

**客户端 ×2**（同一局域网）：
- **A 演奏者**：26.2 原版 → Fabric 安装器装 Loader 0.19.5 → mods 里放 `fabric-api-0.161.0+26.2.jar`（Modrinth 下载）+ `fabric-0.1.0.jar`
- **B 聆听者**：26.2 纯原版，什么都不装

## 阶段 1：插件冒烟（占位音色，无需资源包）

1. `plugins/` 放入插件 jar，启动服务器。
   - ✅ 日志出现 `Chord 启用：乐器 1 个，频道 chord:play / chord:sync`
   - ✅ 生成 `plugins/Chord/config.yml` 和 `instruments.yml`
2. 编辑 `instruments.yml`，把 harmonica 的 `voices` 整段临时替换为单条全区间占位（避免占位音色被钳制丢音）：
   ```yaml
   voices:
     - { min: -12, max: 25, sound: "block.note_block.bit", base-pitch: 1.0 }
   ```
   执行 `/chord reload`。（占位模式只验链路不校音准，高音区会塌到同一音高，正常现象）
3. 客户端 A 进服。
   - ✅ 客户端日志无 chord 异常（F3 → Mod 数量包含 chord，或 Mods 菜单可见）
   - ✅ **握手免操作**：不执行任何 `/chord reload`，进服后手持乐器右键应直接可演奏（不出现「服务器未启用 Chord」提示，或仅在进服后 <1 秒内闪现）；之后进服的每个玩家同样免操作（回归：曾因 REGISTER 时序导致每次进服都要 reload）
4. OP 执行 `/chord instruments` → 列出 `harmonica = 守夜人口琴`；`/chord give harmonica` → A 获得改名山羊角，物品名 Lore 含 "Chord · harmonica"。

## 阶段 2：演奏链路（核心验收）

5. **举起**：A 手持乐器右键。
   - ✅ HUD 出现「守夜人口琴 · 演奏中」和「Shift / 切换快捷栏 退出」
   - ✅ 无山羊角原生吹奏音效、无吹奏抬手动画（**§11 待验证项 3**）
6. **零安装聆听**：B 站在 A 旁 ≤16 格，A 按 `Z`。
   - ✅ **B 听到一个音符盒电音**（本项目的核心价值验收）；A 自己也听到服务端回声
   - ✅ B 离开到 >16 格再听 → 无声（距离衰减生效）
7. **音阶与修饰键**：A 依次按 `Z X C V B N M ,` → 音高递增；按住右键整排高八度；按住左键低八度；按住中键升半音（可与八度叠加）。
   - ✅ HUD 音名闪现与所按键一致（低/高前缀、♯后缀）
   - **直排音（进阶）**：`.minecraft/config/chord.json`（首次启动自动生成，默认 `direct_notes: []`）加入 `{"semitone":0,"label":"1"},{"semitone":1,"label":"1♯"}` 两项 → 重启游戏 → 按键设置里出现「直排音 1/2」且默认未绑定 → 把直排音 1 绑到未占用的键（如 `G`）→ 演奏态按 `G` 出 1、按住右键再按 `G` 出高音 1（修饰键叠加生效）；HUD 显示自定义 label「1」，叠修饰后显示自动简谱名「高1」。把直排音绑到与音级键相同的键（如 Z）→ 只出音级键的音（先匹配先生效，符合文档说明）。
8. **和弦**：同刻按下 `Z C B`（1-3-5）→ 三个音同时响。
9. **音符时长 = 按住时长**（note-off）：轻点 `Z` → 声音在松开后约 0.1~0.3 秒内停止（不再播完整条 3.2s 采样）；按住 2 秒 → 持续约 2 秒；按住超过 3.2 秒 → 采样自然结束（预期行为，非 bug）。
   - **和弦独立停音**：按住 `Z C B` 后先只松开 `C` → `Z`、`B` 两音继续响，`C` 单独停止。
   - **修饰键实时变调**：按住 `Z` 后再按住右键 → 该音在 ≤1 个游戏刻内变为高八度（无需重按）；松开右键 → 回落；先按 `,` 再立刻按左键（ms 级先后）→ 音高应为低八度而非原调；变调后超音域（如低音区按住时再叠升半音出界）→ 该键静音，修饰键恢复后自动回来。
   - **打开界面静音**：按住音符时按 `T` 打开聊天 → 该音立即停止，聊天可正常打字（含 Z X C 等字母），关闭聊天回到演奏态继续。
10. **演奏态键盘隔离**：先在原版按键设置里把「聊天」绑定到 `Z`（复刻其他 Mod/原版占用我们键位的场景）。非演奏态按 `Z` → 打开聊天；举起乐器进入演奏态后按 `Z` → **只出音、不开聊天**；退出演奏态后按 `Z` → 又恢复开聊天。
11. **退出**：Shift 退出 → HUD 消失；再举起，滚轮/数字键切快捷栏 → 也退出；退出后攻击、放方块立即恢复正常（按住音符时退出，音应立即停止）。
12. **原版玩家持乐器**：把乐器丢给 B（无 Mod），B 右键 → 无任何反应（插件已取消原生山羊角吹奏）。
13. **未启用提示**（可选）：A 直接连一台没装插件的服 → 拿不到乐器、Mod 无感不崩溃（负向兼容）。

## 阶段 3：防滥用与命令

14. **限速**：临时把 `config.yml` 的 `notes-per-second` 改为 `5`、`burst` 改 `5`，`/chord reload`，A 快速连打 Z（按下立刻松开）→ 数音后 B 听不到新音、服务端日志出现「音符限速触发」。改回 20/10。
15. **持续音上限**：临时把 `max-simultaneous-notes` 改为 `2`，reload 后按住三个键（`Z C B`）→ 只有前两个音响，第三个无声；改回 6。
16. **手持校验开关**：`require-held-instrument: false` reload 后仍可演奏（证明配置被读取）。真正防伪造包需自动化测试，列后续项。
17. **mute**：B 执行 `/chord mute <A名>` → A 演奏 B 静音（含按住中的音停止）；再执行一次恢复；B 重进服状态保持（`mutes.yml`）。
18. **热重载**：改 `instruments.yml` 的 `display-name` → `/chord reload` → A 重新举起，HUD 标题已变。

## 阶段 4：真实口琴采样（资源包）

19. **打包**：把 `assets/resourcepack/` 内容打成 zip（`pack.mcmeta` 在压缩包根层），算 SHA-1：
    ```bash
    cd assets/resourcepack && python -m http.server 8000   # 局域网托管
    sha1sum chord-pack.zip                                   # 取哈希
    ```
    `server.properties`：
    ```properties
    resource-pack=http://<主机IP>:8000/chord-pack.zip
    resource-pack-sha1=<sha1>
    ```
    （Paper 26.2 若字段名有变，以服务端启动日志提示为准）
20. 还原 `instruments.yml` 的真实 voices（仓库原始内容），`/chord reload`。A、B 都接受资源包。
21. **音色与全音域**（**§11 待验证项 1：pitch 钳制**）：
    - ✅ A 演奏，B 听到的是口琴采样而非电音
    - ✅ 从低八度 `Z`（−12）一路按到高八度 `,`+中键（+25）走全音阶：音高单调递增、无跳变；音区交界处（−7→−8、6→7）只有音色层的自然切换、音高连续
    - ✅ 长按/轻点行为在真实采样下同样成立（按住持续、松开 ~0.3 秒内收尾）
    - ✅ 极端音 −12 与 +25 无破音、无声（若 +20~+25 全部塌成同一音高 = 钳制生效且 voices 区间有误，记录并回报）
22. **拒绝资源包**（V1 已知边界）：B 拒绝资源包 → B 听 A 演奏无声、无报错刷屏（定向回退是 V1.2 功能，本项只验收不崩溃）。

## 阶段 5：Folia 边界与稳定性（**§11 待验证项 2**）

23. **跨区域**：A、B 相距 >500 格（不同 region 线程），B 走回 A 旁 16 格内 → 能听到；A 演奏中持续移动跨区块 → 无异常、无报错。
24. **并发**：两个演奏者（需两台装 Mod 客户端）同时演奏 → 互不干扰。
25. **重连/掉线停音**：A 按住音符中断线重连 → 声音在掉线时停止（服务端 forget 兜底停音）；重连后**无需任何操作**（含 /chord reload）手持乐器右键直接可演奏；从 Chord 服换到另一台服务器再换回，同样直接可演奏且无上一服的乐器表残留。
26. **时长**：连续演奏 5 分钟 + 频繁进出演奏态 → 内存/日志无异常增长。
27. **Geyser**（可选）：接 Geyser 基岩客户端 → 能听到（预计正常，音符盒事件有映射）。

## 阶段 6：钢琴（世界乐器）

前置：更新 mod + 插件 jar、资源包（含钢琴采样）、`instruments.yml`（含 piano 条目）。OP 执行 `/chord piano spawn` 在准星方块上放置。

25. **放置与入口**：A 对交互实体右键 → 进入「三角钢琴 · 演奏中」，HUD 退出提示为「Shift / 走远 退出」；B（原版客户端）右键同一实体 → 收到「需要安装 Chord 模组」提示，无任何异常。
26. **演奏与音色**：键位与口琴一致（ZXCVBNM, + 鼠标修饰）；A 演奏 B 听到钢琴采样；轻点即停（钢琴自然衰减音尾可接受）；和弦按住逐一松开各自独立停音。
27. **距离退出与服务端校验**：A 按住音符走远 → 超过 8 格客户端自动退出、音符停止；会话校验（伪造场景）：A 不右键进入直接发钢琴音符包 → 服务端丢弃（无会话）；A 进入后走出 8 格再发包（保持按住快速跑出）→ 新音符被服务端丢弃（B 听不到）。
28. **与手持乐器切换**：A 手持口琴右键进入口琴态 → 直接右键钢琴 → 自动切到钢琴态（旧音符释放）；反之亦然。
29. **实体生命周期**：`/chord piano spawn` 放置 → 演奏正常；重启服务器后实体标记仍在（PDC 随实体存档）、右键即奏；`/chord piano remove` 移除实体后原地附近发包（伪造）→ 无会话/实体失效，丢弃。
30. **多台并发**：两台钢琴相距 >16 格，两个演奏者同时演奏互不干扰；同一台钢琴两个演奏者轮流进入各自会话独立。
31. **CraftEngine 家具接入（事件路，0.3.0+）**：服务器装 CraftEngine，放好 id 为 `example:player_piano` 的钢琴家具（instruments.yml 的 `world-bind.match-values: ["example:player_piano"]`）→ A（装 Mod）对家具右键**直接**进入演奏态（CE 配置无需任何 per-furniture 设置；CE 的 right_click 占位动作被接管跳过）；B（原版）右键 → 收到安装提示；**音符校验为位置锚点**：A 演奏中走远 >8 格自动退出；拆掉家具后（已知边界）原地仍可弹到走远为止；`/chord piano list` 会话显示「（家具）」锚点。非 Chord 家具（id 不匹配）右键行为与 Chord 存在无关，完全不受影响。旧版 CE（命中箱为真实交互实体）时走 PDC 匹配路：`/chord piano inspect` 查看 → 填 world-bind → `/chord reload`。

## 阶段 7（存档）：乐谱书与自动演奏（0.2.0；**乐谱书链路已分两次移除**——0.7.11 下线服务端导入/录制命令，0.7.15 移除客户端副手书播放，G 键唯一语义 = 打开 MIDI 中心。自动演奏的现代等价物见阶段 17/18：客户端 .mid 现转现播；音符粒子特效部分（34）仍有效）

前置：更新 mod + 插件 jar（协议版本 2，两端必须一起换）；附件 `歌唱祖国-F调完整版.mid`（或任意 format 0/1 MIDI）复制到 `plugins/Chord/scores/`。

32. **导入与成书**：OP 执行 `/chord score import 歌唱祖国-F调完整版` → 收到成书与摘要（425 音符 / BPM 120 / 2/4 / 移调自动 0 / 最大同时音 1 / 30 页）；打开书翻页可见「小节号 + 简谱 + 时值」对照页（对照附件 txt：小节 1 应为 高1 高1 高1 / 16 16 4·）；`/chord score info` 主手/副手持书均显示摘要。**文件名含空格**：把文件重命名为「歌唱祖国 F调完整版.mid」再 `/chord score import 歌唱祖国 F调完整版` → 仍能导入（尾词不是数字时归入文件名）；`+2` 尾参数则识别为移调。**多声部 MIDI**：导入双手钢琴谱（或自制多轨 MIDI）→ 摘要提示「已收敛为单旋律」；同文件加尾参 `和弦` → 和弦保留、摘要报「八度折叠 N」（超低音升八度入域）；移调后仍出界的音不再出现「域外跳过」（转换即 100% 可演奏）。
33. **自动演奏全链路**：A（装 Mod）副手拿乐谱书、主手举口琴右键进入演奏态 → HUD 出现「副手乐谱《…》· 按自动演奏键开始」→ 按 `G` → 紫色进度行出现（小节 i/173、音符 i/425 递增），A 自听与 B（原版客户端）听到的旋律一致，节奏与 MIDI 对得上（首句「高1 高1 高1」三连音）。
34. **特效与提示**：B 观察 A——手动演奏时每个音符头顶冒 1 个彩色音符粒子（音高对应色相、高音更偏暖）；A 按 `G` 开始自动演奏时头顶爆发一大簇三色音符 + 白色光点，期间每个音符为**金色音符 + 白色光点**，结束时小簇收尾；**全程聊天栏/actionbar 无任何广播消息**（远处听不到的玩家不被打扰）。`config.yml` 把 `note-particles: false` → 手动粒子消失；`auto-particles: false` → 自动演奏无金色/白光/爆发；`/chord reload` 生效。若仍看不到粒子：查服务端日志有无「音符粒子发送失败」WARNING（首例带堆栈，回报给开发）。
35. **打断与停止**：自动演奏中 A 按任意音级键 → 自动立即停止（服务端收到 STOP）转为手动演奏；换掉副手书 → 自动停止并闪「乐谱书不在副手」；蹲下退出演奏态 → 停止且无残留长音；演奏中 A 直接按 `G` → 停止并闪「停止自动演奏」。
36. **边界**：副手没书按 `G` → 闪「副手没有乐谱书」，无其他副作用；`/chord score transpose 2` 后 info 显示移调 +2、自动演奏整体高 2 半音（书页简谱同步变化）；钢琴（世界乐器）演奏态下副手持书按 `G` 同样可自动演奏；自动音符受既有限速/和弦上限约束（用一份密集 MIDI 验证不刷屏、无报错刷屏）；服务器把 `limits.notes-per-second` 临时降到 3 → 快速段落明显丢音（符合限速语义），恢复 20。

## 阶段 8：释放行为与闷音键（0.3.0 落地，0.5.0 起以吉他/鼓为 decay 验证对象——钢琴已改 sustain，见阶段 11）

前置：mod + 插件 jar 一起换（InstrumentDef 线格式变了，两端必须同版本）；instruments.yml 吉他/贝斯/鼓段 `release-mode: decay`；config.yml 限速改 25/15。

37. **decay 自然衰减（吉他）**：A `/chord give guitar` 右键进入演奏态 → 按一个音立刻松开 → B 听到声音**不被立刻掐断**，而是自然衰减出音尾（约 3 秒）；快速点按多个音，每个音各自衰减、互不截断（对比口琴的「松键即哑」）。
38. **口琴不变**：A 手持口琴按音松开 → 立刻停止（气息乐器行为同旧版）；确认 instruments.yml 口琴段没有 release-mode 或为 stop。
39. **变调重击不再突兀（吉他）**：A 按住一个音 → 按住鼠标右键升八度 → 宽限窗口外旧音自然延续、新音同时起（没有「重新弹一遍」的切断感）；和弦按住 + 变调 + 逐个松键全过程中无掐断、无重弹感。
40. **闷音键（decay 乐器）**：吉他弹几个音留余音 → 按 `K` → 所有声音（含按住中的）立刻停止；松开 K 不恢复；HUD 提示行显示「· K 闷音」（钢琴显示「· K 延音」）。改键后在控件设置验证。
41. **退出硬止音**：A 留余音时蹲下退出演奏态 / 走远 8 格退出（钢琴）/ 打开聊天再关闭 → 退出路径余音立刻停止（打开界面瞬间松开的音允许自然衰减）；A 直接断线 → 服务端 forget 硬止音，B 侧无残留长音。
42. **余音防刷**：A 快速连打 25+ 个不同音 → 最旧的余音被自动掐掉（服务端余音上限 24，0.5.0 起钢琴踏板期间同样受限）；日志无限速告警刷屏。

## 阶段 9（存档）：演奏录制（0.3.1，零客户端改动）

前置：只需更新插件 `plugin-0.3.1.jar`（客户端、协议、配置都不动）。

46. **时长与边界**：长按音录制出的时值 ≈ 实际按住时长（自动播放时松开即停/自然衰减符合乐器模式）；重复快速同音各成短音不粘连（同半音重触发截断）；录制期间把副手书换走 → 录制自动结束并弹保存询问；`/chord score record save 我的曲子` 可带曲名保存；少于 3 个音的录制提示太短不保存；钢琴（世界乐器）+ 空白书同样可录。

## 阶段 11：钢琴延音踏板（0.5.0，协议版本 5）

前置：**mod + 插件都换 0.5.0**（协议 v5：chord:pedal 频道 + note-off bit3 + InstrumentDef bit1；旧组合会卡音或禁用演奏）；instruments.yml 钢琴段改 `release-mode: sustain` 后 `/chord reload`。

56. **默认制音（核心语义）**：A 右键钢琴 → 按一个音立刻松开（不踩踏板）→ B 听到约 150ms 短缓冲后即被制音，**不是** 0.3/0.4 的「自然衰减 2.5 秒」——听感像真钢琴没踩踏板抬键。对比：口琴松键立刻硬停（无缓冲）、吉他松键自然衰减。
57. **延音踏板（hold）**：A 按住 `K` 不放 → 弹几个音逐个松键 → 所有音**继续自然衰减**（踩住期间松键不制音）；保持 K 按住的同时按新的音也正常；松开 `K` → 所有「键已松开」的余音立刻被掐；**按住中的键不受影响**（松开 K 时仍在按的音继续响）。HUD 踩下期间显示「♪ 延音中」（绿色），未踩显示「K 延音」。
58. **踏板时机捕捉**：A 按音 → 松键 → **150ms 内**立刻踩下 K → 该音被接住继续延音（不是被制音）；松键超过半秒再踩则接不住（已被制音）。连续踩放 K 不发声、不报错。
59. **重击与制音器**：踩住 K 弹同度音（直排音绑同半音两个键）→ 新音正常起、旧余音延续（余音表路径）；不踩 K 快速重复同音 → 每次都是「落弦-击弦」（150ms 缓冲被重击取消，无残留）；修饰键变调宽限窗口内的 off/on 对（钢琴）走制音缓冲路径，听感为干净的换音重击。
60. **自动演奏与录音**：钢琴 + 副手乐谱书 `G` 自动演奏 → 音符按谱面时值制音（自动引擎不踩踏板，长音谱面听感正常）；踩住 K 期间开自动演奏 → 谱内松键的音全部延音、松开 K 一起收；录制：踩踏板演奏后保存的书，回放时延音效果不复制（踏板不是音符事件，谱面只有时值——预期行为）。
61. **边界**：A 留延音余音时蹲下退出 / 走远退出 / 断线 → 余音立刻停（硬止音含制音缓冲表）；打开聊天再关闭 → 松键瞬间若踩着 K 余音保留，未踩则按默认制音；吉他/鼓按 K 仍为瞬时闷音（回归确认）；口琴 K 无操作。

65. **八度锁（双击左/右键）**：双击右键 → 闪现「♯ 高八度锁」，HUD 显示指示 → 按 Z 出高 1（+12）；锁住后**再按住右键**按 Z → 出高高 1（+24）；双击左键同理得低八度锁（−12）、锁住后按住左键 → 低低 1（−24）；再双击同侧键解锁回 0。高锁与低锁互斥（后设的替换先设的）。锁定状态下宽限变调窗口照常（按音 150ms 内改变修饰会修正音高）。
66. **力度与既有机制交互**：滚轮调到 ff 后踩延音踏板弹和弦再松 → 延音的是强音层的音（力度在 note-on 时定格，余音/制音不受后续滚轮影响）；自动演奏（G）不受滚轮影响恒基准力度；录制不记录力度（回放恒基准，CHSC v2 再议——预期行为）；退出演奏态后力度/八度锁/踏板锁全部复位（再进入默认 100/无锁/止音模式）。

|---|---|
| 手持乐器 HUD 显示「服务器未启用 Chord」 | 客户端是否真的装了 Mod；服务端日志频道注册行；A 的客户端日志有无 payload 注册异常 |

| 音色是电音而非口琴 | 资源包未被接受（客户端 选项→资源包）；voices 是否被还原为采样版本 |

| 钢琴 高高2(+26) 以上 / 低低音(−24~−13) 无声，+24/+25 正常 | 客户端资源包是旧版：旧 sounds.json 钢琴逐半音事件只覆盖 −12~+25（音域边界恰好对上）。换发最新 chord.zip 并让客户端重下；若按这些音还闪「超出音域」，服务器 instruments.yml 也是旧版（`/chord instruments` 应显示钢琴 半音 -39~48） |

## 阶段 19：小提琴（0.8.0，协议 v6 不变——纯服务端数据 + 资源包扩展）

前置：插件与模组换 0.8.0（版本对齐即可，旧 0.7.x 客户端对新增乐器同样兼容——sync 是通用表）；资源包更新（新增 violin 采样 30 个 ogg 与 sounds.json 122 个 violin 事件）；服务端 `instruments.yml` 手动同步 violin 段后 `/chord reload`，`/chord instruments` 应列出 6 种乐器。

101. **物品链路与进入**：`/chord give violin` → 获得木棍；手持右键进入演奏态（木棍无原生使用行为，右键无副作用——这是选 STICK 而非 BOW 的原因，弓会拉弦放箭）；HUD 显示「小提琴 · 演奏中」。
102. **音域与灰显**：音级键默认可达 [0,+25]；叠低八度修饰键弹 G3~B3（−5~−2，小提琴最低音 G 弦），再往下（<−5）键位灰显静音；直排音绑 +26~+40 能出 C6~E7 高音区。顶部 E7（+40）正常发声无钳制失真，+41 以上静音。
103. **anchor 路由听感**：沿 G 大调音阶从 G3 上行到 G5，相邻音无「换采样」跳变色（15 锚点网格拉伸 ≤±2 半音，透明变速）；重点听 C4 交界（−1/+1 用 C4 采样、+2 起 E4 采样）与 G6（+30/+31，该锚点 f 层揉弦最深）。
104. **力度分层（滚轮）**：演奏态滚轮把力度调到 63 以下 → 音色变暗变柔（vl-p 柔音层）；调回 64+ → 恢复常规 vl-f 层。**边界听感：跨 63/64 只变音色不变响度**（两层同 RMS 对齐 −11.3dB，无跳变）；同力度下柔音层不比常规层响。
105. **release 语义（stop）**：松键立刻止音（弓离弦），无余音无衰减尾；`K` 键无操作（stop 模式无闷音/踏板）；按住超 3s → 采样淡出自然结束（预期行为，非 bug）。
106. **MIDI 输入路由**：MIDI 键盘/直播小提琴声部（G3 以上）→ 全域可用；复音 >6 时收敛单旋律（max-polyphony 6，双音/三音和弦可叠）；力度 ≤63 的 MIDI 音符走柔音层。
107. **降级音色**：未接受资源包的聆听者听到音符盒 flute 音色（fallback-voices，[-12,+12] 域内），域外音无声（与其他乐器同口径）。
108. **世界乐器声源位置（0.8.0）**：B 站在钢琴旁、A 蹲在琴另一侧演奏 → B 听到的声音**从琴的方向传来**（3D 定位随琴的位置，不随 A 的位置）；A 绕琴走动一周，声源方向固定不变；B 走离琴 16 格以上→无声（可听距离从琴算起，不再从演奏者算）；**音符粒子仍在 A 头顶**（声源与特效分离是验收点）；手持乐器（小提琴/口琴）声源仍跟随演奏者本人；钢琴松键的制音尾音同样从琴的位置播出（与主音同源、无位置跳变）。
